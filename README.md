## 📁 Sobre este repositorio

Este es el código de mi portfolio personal, diseñado y desarrollado desde cero con **Angular** y **Tailwind CSS**. Está organizado en componentes reutilizables y el contenido (proyectos, experiencia, stack) vive separado de la vista, en archivos de datos tipados.

```bash
git clone https://github.com/PablinkiDev/portfolio.git
cd portfolio
npm install
npm start        # http://localhost:4200
```
